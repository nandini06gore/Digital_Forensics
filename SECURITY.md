# Security Policy

## Scope

This repository contains educational documentation, sample datasets, and helper scripts for digital forensics and incident response.

## Reporting a vulnerability

If you identify a security issue in repository code or workflows, do not publish exploit details in a public issue. Contact the repository maintainers through GitHub's private vulnerability reporting feature, if enabled, or another private channel listed in the repository profile.

Include:
- A concise description and affected path/version.
- Reproduction steps using a safe test environment.
- Potential impact.
- Suggested mitigation, if known.

## Safe use

- Use tools only on systems and data you own or are authorized to investigate.
- Treat collected evidence as potentially sensitive.
- Do not upload production evidence, credentials, private keys, tokens, or personal information.
- Run potentially risky analysis only in isolated, disposable environments.
