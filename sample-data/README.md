# Sample Data Policy

This directory is reserved for synthetic or explicitly redistributable public training data.

Before adding a dataset:
- Confirm its license and redistribution terms.
- Remove credentials, personal data, customer information, and confidential identifiers.
- Document provenance, creation method, timezone, and known limitations.
- Include hashes and a short description.
- Do not commit real production logs, memory dumps, disk images, or packet captures without explicit authorization and review.

Large datasets should be linked from their authoritative source rather than copied into Git.
